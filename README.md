# Grove

A personal memory and life-documentation app visualised as a living 3D tree.

**→ Read [START_HERE.md](./START_HERE.md) for the full picture: what's built, what's missing, and the open design questions.**

---

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 14 (App Router, TypeScript)
- Three.js + React Three Fiber + Drei
- Framer Motion
- Tailwind CSS
